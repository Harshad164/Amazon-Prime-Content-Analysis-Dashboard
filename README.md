# # Amazon Prime Content Analysis Dashboard

Goal: To analyze Amazon Prime's content library and identify trends in movies and TV shows based on country, release year, content type, ratings, and genres.

Tools Used: Microsoft Power BI

Concepts Used: Data Cleaning, Data Visualization, Data Analysis, KPI Cards, Slicers, Charts, and Interactive Dashboard Development.

Key Insights:
- Analyzed the distribution of Movies and TV Shows.
- Identified content availability across different countries.
- Examined content release trends over the years.
- Analyzed content distribution based on ratings.
- Identified the most common genres and categories.
- Developed an interactive dashboard to explore Amazon Prime content.

Dashboard Features: Country-wise Content Distribution, Release Year Analysis, Content Type Analysis, Rating Analysis, Genre Analysis, and Interactive Filters.

Software: Microsoft Power BI Desktop
